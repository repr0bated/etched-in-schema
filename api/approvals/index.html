Approvals: two-approval root, policy co-signer, break-glass.

Implements docs/APPROVALS-SPEC.md §§4–7 as pure code: structured requests, canonical argument hashing, the co-signer truth table, and single-use tickets. No I/O, no network, no clock access — now is always passed in, so every path is deterministic and testable.
